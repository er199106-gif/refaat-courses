# 🎓 Refaat Courses - منصة تعليمية تفاعلية

منصة تعليمية شهرية موجهة للأطفال (7-9 سنوات) تجمع بين التفكير المنطقي، التصميم الإبداعي، الذكاء الاصطناعي، والمشاريع التطبيقية بأسلوب لعبة تعليمية.

![Refaat Courses](https://via.placeholder.com/800x400/6C63FF/FFFFFF?text=Refaat+Courses)

## ✨ المميزات

- 🧠 **قسم التفكير**: أسئلة منطقية ورياضيات ولغات
- 🎨 **قسم التصميم**: مهام إبداعية باستخدام Canva
- 🤖 **الذكاء الاصطناعي**: تعلم استخدام AI بشكل إيجابي
- 🧩 **المشاريع**: مشاريع أسبوعية تطبيقية
- 🏆 **الإنجازات**: نظام مكافآت وتحفيز مستمر
- 👨‍👩‍👦 **لوحة ولي الأمر**: تتبع التقدم دون تعديل المحتوى
- 🤖💬 **المساعد الذكي**: دعم تعليمي فوري
